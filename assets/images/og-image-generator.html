How to save this as OG Image:

  1. Open this file in Chrome browser
  2. Right-click on the image above
  3. Select "Inspect" to open DevTools
  4. In DevTools, right-click on the .og-image element
  5. Select "Capture node screenshot"
  6. Save as og-image.png in the same folder

OR use a screenshot tool to capture the 1200x630 box above and save it as og-image.png
